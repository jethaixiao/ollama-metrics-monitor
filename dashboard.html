怎么用这个看板客户端里填下面这四项，调用就会自动被统计
__BASE__/v1/chat/completions
本机地址
__LOCAL_BASE__跑在这台机器上的 DSH / 脚本用这个，不需要 Token
公网地址
__BASE__/v1别的设备用这个，必须带 Token；只收完整路径时填 __BASE__/v1/chat/completions
模型名称
qwen2.5:7b qwen3:14b qwen3:14b-abliterated deepseek-r1:14b必须是 ollama list 里的全名
API Token
__ACCESS_CODE__客户端里的 API Key 字段就填这串；公网调用放 Authorization: Bearer；页面登录用的也是它
命令行
curl -s __BASE__/v1/chat/completions \ -H 'Content-Type: application/json' \ -H 'Authorization: Bearer __ACCESS_CODE__' \ -H 'ngrok-skip-browser-warning: true' \ -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"hi"}]}'
import requests resp = requests.post( "__BASE__/v1/chat/completions", headers={"Content-Type":"application/json", "Authorization":"Bearer __ACCESS_CODE__", "ngrok-skip-browser-warning":"true"}, json={"model":"qwen2.5:7b","messages":[ {"role":"user","content":"你好"}],"temperature":0.7}) print(resp.json())
const r = await fetch( "__BASE__/v1/chat/completions",{ method:"POST",headers:{"Content-Type":"application/json", "Authorization":"Bearer __ACCESS_CODE__", "ngrok-skip-browser-warning":"true"}, body:JSON.stringify({model:"qwen2.5:7b", messages:[{role:"user",content:"你好"}],temperature:0.7})}); console.log(await r.json());
curl -X POST \ "__BASE__/v1/chat/completions" \ -H "Content-Type: application/json" \ -H "Authorization: Bearer __ACCESS_CODE__" \ -H "ngrok-skip-browser-warning: true" \ -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"你好"}],"temperature":0.7}'
